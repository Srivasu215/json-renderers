How to Create HTML Tables
Using CDN & window.ks

If you have never built a dynamic HTML table from JavaScript before, this guide is made for you! Learn how to turn a list of JSON records into an interactive, beautifully structured HTML table in the browser without writing manual <tr> and <td> loop code.

💡 How it Works ⚡ Method 1: Direct CDN Import 🌐 Method 2: Global window.ks ⚖️ Side-by-Side Comparison 🎮 Live Interactive Demo
Step 0: The Big Picture

What Happens When You Render a Table?

Understanding the 4 simple stages under the hood.

1 Data Source

Raw JSON Data

You provide plain JavaScript objects, like records from an API or a JSON file: 

[
  { "itemName": "Item A", "baseUnit": "kgs" },
  { "itemName": "Item B", "baseUnit": "pcs" }
]
Input Data →
2 Runtime Call

json-renderers Call

You call the renderer with your chosen columns and the target element ID: 

render({
  type: "table",
  data: data,
  columns: ["itemName", "baseUnit"],
  targetHtmlId: "container"
});
Orchestrator →
3 Spec to Tag

JSON Blueprint to DOM

json-renderers-build creates a table schema, and @keshavsoft/json-to-tag converts that schema into real DOM nodes:

<table>
  <thead><tr><th>...</th></tr></thead>
  <tbody><tr><td>...</td></tr></tbody>
</table>
Native DOM Creation →
4 DOM Mount

Container Mounted

The engine automatically inserts the finished table into your container: 

<div id="container">
  <!-- Fully rendered table appears here! -->
</div>

Method 1: Direct CDN Import

▶️ Run samples/tableByCdn in Browser →

How It Works in Simple Words

In this method, your JavaScript file imports the render function directly from the CDN link as an ES Module. You then call render({...}) with your data and options.

1. index.html (The HTML page) 
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Table via CDN - json-renderers</title>

  <!-- Bootstrap CSS for clean table styling -->
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body class="bg-light">
  <main class="container-fluid py-4">
    <h1>Table DOM Renderer Demo</h1>

    <!-- 1. Target container where table will be mounted -->
    <div id="dom-render-container">
      <div class="text-center py-5 text-muted">Rendering table to DOM...</div>
    </div>
  </main>

  <!-- 2. Load our module script -->
  <script type="module" src="./index.js"></script>
</body>
</html>

Notice: The only requirement in HTML is an element with an id (like dom-render-container) and <script type="module" src="./index.js"></script>.

2. index.js (The JavaScript logic) 
// 1. Import the default render function directly from jsDelivr CDN
import render from "https://cdn.jsdelivr.net/gh/keshavsoft/json-renderers@main/docs/dist/v14/min.js";

// 2. Import your JSON data (or fetch it)
import data from "./batches.json" with { type: "json" };

const start = () => {
  try {
    // 3. Call render with your configuration
    render({
      type: "table",
      data: data.slice(0, 50),                 // Only first 50 rows for performance
      targetHtmlId: "dom-render-container",     // Must match HTML div id
      columns: ["itemName", "baseUnit"],       // Columns to display
      showLog: true                            // Prints debug logs in browser console
    });
  } catch (err) {
    console.log("error : ", err);
  }
};

start();

Key Feature: Direct modular import. Clean, explicit, and self-contained.

Sample: samples/tableByKs

Method 2: Global window.ks Namespace

▶️ Run samples/tableByKs in Browser →

How It Works in Simple Words

In this method, the CDN script is imported for its side effects (or loaded as a script tag). When loaded, the bundle automatically attaches itself to the browser's global scope: window.ks.jsonRenderers.renderToDom. You can call this global function from anywhere in your web application!

1. index.html (The HTML page) 
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Table via KS - json-renderers</title>

  <!-- Bootstrap CSS -->
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body class="bg-light">
  <main class="container-fluid py-4">
    <h1>Table DOM Renderer Demo</h1>

    <!-- Target container where table will be mounted -->
    <div id="dom-render-container">
      <div class="text-center py-5 text-muted">Rendering table to DOM...</div>
    </div>
  </main>

  <!-- Load your module script -->
  <script type="module" src="./index.js"></script>
</body>
</html>

The HTML markup is identical! The difference is in how the JavaScript accesses the renderer.

2. index.js (Using window.ks) 
// 1. Load the CDN bundle (it registers window.ks globally)
import "https://cdn.jsdelivr.net/gh/keshavsoft/json-renderers@main/docs/dist/v14/min.js";

// 2. Import your JSON data
import data from "./batches.json" with { type: "json" };

const start = () => {
  try {
    // 3. Call the globally attached function:
    // window.ks.jsonRenderers.renderToDom(...)
    window.ks.jsonRenderers.renderToDom({
      type: "table",
      data: data.slice(0, 50),
      targetHtmlId: "dom-render-container",
      columns: ["itemName", "baseUnit"],
      showLog: true
    });
  } catch (err) {
    console.log("error : ", err);
  }
};

start();

Key Feature: Perfect when multiple scripts, legacy code, or inline buttons need access to window.ks without re-importing.

Which method should you pick for your project?

Aspect tableByCdn (Direct Module) tableByKs (Global Window)
Import Statement import render from "..."; import "...";
Execution Function render({ ... }); window.ks.jsonRenderers.renderToDom({ ... });
Global Scope Pollution Does not modify window (clean encapsulation) Attaches to window.ks.jsonRenderers
Best Used For Modern ES Module projects, clean modular architecture Multi-script setups, browser console testing, CMS pages

Parameter Guide

All Configuration Options Explained

Everything you can pass to the render function.

type Required

Specify "table" to instruct the builder to construct an HTML table component.

type: "table"
targetHtmlId Required

The id of the DOM element on your page where the table should be mounted.

targetHtmlId: "dom-render-container"
data Required

An array of JavaScript objects containing the rows of information you want to display.

data: [ { itemName: "...", ... } ]
columns Recommended

Array of object keys to render as columns in the table header and body. Filters out unwanted keys.

columns: ["itemName", "baseUnit"]
showLog Optional

Boolean (true / false). Enables informative console debug messages.

showLog: true
appendPosition Optional

Set to "prepend" to add before existing content, or omit to replace content.

appendPosition: "prepend"
💡

How to Load Data Using fetch() Instead of JSON Import

If your browser doesn't support import data from "./data.json" with { type: "json" }, or if you are retrieving live data from a REST API backend, use the standard modern fetch() API: 

// 1. Import renderer
import render from "https://cdn.jsdelivr.net/gh/keshavsoft/json-renderers@main/docs/dist/v14/min.js";

// 2. Fetch the JSON file or API endpoint
async function loadTable() {
  try {
    const response = await fetch("./batches.json");
    const data = await response.json();

    // 3. Mount table into DOM
    render({
      type: "table",
      data: data.slice(0, 20),
      targetHtmlId: "dom-render-container",
      columns: ["itemName", "baseUnit"]
    });
  } catch (error) {
    console.error("Failed to load table:", error);
  }
}

loadTable();
