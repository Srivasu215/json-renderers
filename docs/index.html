Ecosystem Story: DOM Mounting Runtime

Render Business JSON into Live DOM
Powered by json-renderers-build + json-to-tag

The real DOM magic happens in @keshavsoft/json-to-tag. Before that, data may be shaped in json-transformer, a component blueprint is built in json-renderers-build, and json-renderers simply orchestrates the runtime flow and mounts the final HTML into the browser container.

Inside the Builder

What the runtime actually asks for

The runtime does not hand-code table or select DOM. It asks for a JSON blueprint and then lets json-to-tag create real elements.

Table Spec 📊 
{
  "type": "table",
  "children": [
    { "type": "thead", "children": [{ "type": "tr", "children": ["Name", "City", "Amount"] }] },
    { "type": "tbody", "children": [
      { "type": "tr", "children": ["Alpha", "Hyderabad", 1200] },
      { "type": "tr", "children": ["Beta", "Bengaluru", 2200] }
    ] }
  ]
}
Select Spec ▣ 
{
  "type": "select",
  "id": "city-select",
  "children": [
    { "type": "option", "value": "Hyderabad", "text": "Hyderabad" },
    { "type": "option", "value": "Bengaluru", "text": "Bengaluru" },
    { "type": "option", "value": "Pune", "text": "Pune" }
  ]

Ecosystem Architecture

The "In-Between" Handoff Story

How json-transformer, json-renderers-build, json-to-tag, and json-renderers work together.

Step 1 • Spec Request 📦

json-renderers-build

json-renderers calls jsonRenderBuild({ type, data, columns }). The builder matches the skeleton blueprint (table, select) and evaluates it with json-to-spec.

Returns: specAsJsonToDom (AST)
Step 2 • Instantiation 🏷️

@keshavsoft/json-to-tag

The generated specification AST is unwrapped (if fragment) and handed to jsonToTag(spec). Real browser DOM elements (HTMLTableElement, DocumentFragment) are constructed.

Returns: content (DOM Node / List)
This Repo
Step 3 • Container Mount 🖥️

json-renderers

Locates document.getElementById(targetHtmlId). Clears or prepends content based on appendPosition, mounts the nodes, and returns the mounted container.

container.append(content)

Component Catalog

Supported Renderers in v13

type: "table" Data Grid

Mounts complete Bootstrap-styled table into the target element. Supports multi-column headers and automated cell value bindings.

render({ type: "table", targetHtmlId, data, columns })
type: "select" Select Element

Mounts a newly created <select id="LedgerName"> populated with child option elements into the target container.

render({ type: "select", targetHtmlId, data })
type: "selectOptionsOnly" Option Injection

Populates dynamic option items directly into a pre-existing <select> element without modifying outer wrapper tags.

render({ type: "selectOptionsOnly", targetHtmlId, data })
