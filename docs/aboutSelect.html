How to Create HTML Select Dropdowns
Using CDN & window.ks

Need to render a dynamic <select> element from an array of strings or records in JSON? This tutorial shows you how to populate and mount a fully functional dropdown in the browser DOM in just a few lines of code—without hand-crafting <option> loops or string concatenation.

💡 How It Works ⚡ Method 1: byCdn (Direct Import) 🌐 Method 2: byKs (window.ks) ⚖️ Comparison 🎮 Live Interactive Demo

Method 1: Direct CDN Import (byCdn)

▶️ Run samples/select/byCdn →

How byCdn Works

In this setup, your JavaScript file imports the default render function directly from the CDN link as an ES Module. Then, you call render({ type: "select", data, targetHtmlId }).

1. index.html (HTML Markup) 
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Select DOM Renderer Sample - json-renderers</title>

  <!-- Bootstrap CSS for clean dropdown styling -->
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body class="bg-light">
  <main class="container-fluid py-4">
    <h1>Select DOM Renderer Demo</h1>

    <!-- 1. Target container where the <select> is mounted -->
    <div id="dom-render-container">
      <div class="text-center py-5 text-muted">Rendering select dropdown...</div>
    </div>
  </main>

  <!-- 2. Load ES Module script -->
  <script type="module" src="./index.js"></script>
</body>
</html>

The container #dom-render-container is all that the runtime needs. The old placeholder content is replaced automatically.

2. index.js (JavaScript Logic) 
// 1. Import render directly from jsDelivr CDN
import render from "https://cdn.jsdelivr.net/gh/keshavsoft/json-renderers@main/docs/dist/v14/min.js";

// 2. Import JSON data
import data from "./data.json" with { type: "json" };

const start = () => {
  try {
    // 3. Render select dropdown
    render({
      type: "select",
      data: data.LedgerName,               // Array of option items
      targetHtmlId: "dom-render-container", // Target container ID
      showLog: false
    });
  } catch (err) {
    console.log("error : ", err);
  }
};

start();

Advantage: Self-contained, tree-shakeable, and standard modern ES module behavior.

Method 2: Global window.ks (byKs)

▶️ Run samples/select/byKs →

How byKs Works

In this setup, you import the CDN bundle once for its side-effects (import "https://...";). The bundle automatically attaches its rendering method to the global browser scope: window.ks.jsonRenderers.renderToDom.

1. index.html (HTML Markup) 
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Select DOM Renderer Sample - json-renderers</title>

  <!-- Bootstrap CSS -->
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body class="bg-light">
  <main class="container-fluid py-4">
    <h1>Select DOM Renderer Demo</h1>

    <!-- Target container -->
    <div id="dom-render-container">
      <div class="text-center py-5 text-muted">Rendering select dropdown...</div>
    </div>
  </main>

  <!-- Load Module script -->
  <script type="module" src="./index.js"></script>
</body>
</html>

The HTML markup is identical between both methods, keeping your page structure clean.

2. index.js (Using window.ks) 
// 1. Load bundle for side effects (registers window.ks)
import "https://cdn.jsdelivr.net/gh/keshavsoft/json-renderers@main/docs/dist/v14/min.js";

// 2. Import JSON data
import data from "./data.json" with { type: "json" };

const start = () => {
  try {
    // 3. Call the globally attached function:
    // window.ks.jsonRenderers.renderToDom(...)
    window.ks.jsonRenderers.renderToDom({
      type: "select",
      data: data.LedgerName,
      targetHtmlId: "dom-render-container",
      showLog: false
    });
  } catch (err) {
    console.log("error : ", err);
  }
};

start();

Advantage: Ideal when other files or scripts need to render selects without importing render repeatedly.

Options Guide

Select Configuration Options

Everything you can pass to the render function for select dropdowns.

type Required

Must be "select" to render a select dropdown.

type: "select"
targetHtmlId Required

The id of the element where the select element will be mounted.

targetHtmlId: "dom-render-container"
data Required

An array of strings (e.g. ["Option 1", "Option 2"]) or objects.

data: ["HDFC Bank", "SBI"]
showLog Optional

Boolean (true / false). Enables console debug information.

showLog: false

How to Populate Select Using fetch() from a REST API

If you are fetching options asynchronously from a backend endpoint or a local JSON file, wrap the call inside an async/await function: 

// 1. Import renderer
import render from "https://cdn.jsdelivr.net/gh/keshavsoft/json-renderers@main/docs/dist/v14/min.js";

async function loadDropdown() {
  try {
    // 2. Fetch the JSON data
    const response = await fetch("./data.json");
    const json = await response.json();

    // 3. Mount select dropdown into DOM
    render({
      type: "select",
      data: json.LedgerName,               // e.g. ["Bank A", "Bank B", "Bank C"]
      targetHtmlId: "dom-render-container"
    });
  } catch (error) {
    console.error("Failed to load select options:", error);
  }
}

loadDropdown();
